ToolBox Qt 客户端（免安装便携版 · 纯本地）

【怎么跑】
双击 ToolBoxQt.exe 即可。本文件夹自带全部 Qt 运行环境（Qt6 DLL、平台/样式/图片插件、
MinGW 运行时），目标电脑不需要安装 Qt 或任何运行库。

【纯本地 · 数据不外传】
- 全部数据保存在本文件夹的 ToolBox\ 子目录（各功能一个 json 文件）
- 不写 C 盘、不上传任何服务器；卸载删除文件夹即可清理干净
- 设置页提供「数据备份」：一键导出全部 json 到任意文件夹，导入后重启生效

【功能地图 · 14 个大类】
- 我的工具箱    签到积分 / HWID / 快捷入口 / 帮助资源
- 系统工具      系统信息 / 全局热键连点器 / 进程监控器 / 启动项查看 / 定时关机重启锁屏
- 效率生活      剪贴板历史（可搜索）/ 记账本（月度支出图表）/ 桌面便签
                番茄钟（联动白噪音）/ 倒计时 / 秒表 / 文本朗读 / 随机决策 / 日期计算 / 世界时钟
- 文本工具      文本脱敏 / AES-256 加解密 / 文件校验（MD5/SHA）/ 开发工具箱 / 代码片段库 / 文本对比
- 网络工具      翻译 / 汇率（央行价）/ 网络诊断（IP 归属地）/ 网速测试 / 端口查看
                批量测活 / HTTP 测试 / 多线程下载器（断点续传+队列）/ 天气
- 截图与媒体    截图 / 文字识别 OCR（离线）/ 屏幕取色器 / 屏幕测距 / 图片工具 / 白噪音
- 文件工具      快捷启动 / 批量重命名 / 重复文件清理 / 文件转码 / 文件搜索 / 磁盘助手 / 系统清理
- 云养宠物      投喂 / 打工赚积分 / 商店 / 桌宠（像素级点击穿透，不挡下层窗口）
- 待办清单 · 日程（倒数日+每日提醒+月历） · 习惯打卡（奖励积分） · 笔记（导出 TXT） · 密码库

【全局快捷键】
- Ctrl+Alt+A    一键截图（选区 → 自动进剪贴板）
- Ctrl+Alt+P    召唤桌宠

【其他】
- 左下角用户卡片悬停可看数据说明；设置页可换主题色、开关动态渐变背景
- 每个大类页会记住你最后停留的工具；窗口大小位置自动记忆
- 主窗口点 X 是隐藏到托盘，退出请走托盘图标右键菜单
